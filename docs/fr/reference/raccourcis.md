# Raccourcis clavier

La liste est aussi dans l'application : **Aide > Raccourcis clavier...**

## Fichier

| Raccourci | Action |
|---|---|
| `Ctrl+N` | Nouveau domaine |
| `Ctrl+Shift+N` | Nouvelle structure (exemple) |
| `Ctrl+O` | Ouvrir |
| `Ctrl+S` | Enregistrer (en mode exercice : enregistrer ma copie) |
| `Ctrl+E` | Exporter en JSON |
| `Ctrl+I` | Générer le script d'import depuis AD |
| `Ctrl+Shift+R` | Exporter le rapport de documentation |
| `Ctrl+Shift+M` | Importer une description (.md) |

## Édition

| Raccourci | Action |
|---|---|
| `Ctrl+Z` | Annuler |
| `Ctrl+Y` ou `Ctrl+Shift+Z` | Rétablir |
| `Ctrl+C` / `Ctrl+V` | Copier / coller un objet et ses enfants |
| `F2` | Renommer |
| `Suppr` | Supprimer |

## Analyse

| Raccourci | Action |
|---|---|
| `Ctrl+Shift+A` | Audit de sécurité |
| `Ctrl+Shift+K` | Chemins d'attaque |
| `Ctrl+Shift+B` | Avant / après |
| `Ctrl+D` | Délégations |
| `Ctrl+T` | Évolution du domaine (comparer deux fichiers) |
| `Ctrl+Shift+S` | Sites AD |
