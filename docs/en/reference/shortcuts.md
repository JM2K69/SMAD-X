# Keyboard shortcuts

The list is also in the application: **Help > Keyboard shortcuts...**

## File

| Shortcut | Action |
|---|---|
| `Ctrl+N` | New domain |
| `Ctrl+Shift+N` | New structure (sample) |
| `Ctrl+O` | Open |
| `Ctrl+S` | Save (in lab mode: save my submission) |
| `Ctrl+E` | Export to JSON |
| `Ctrl+I` | Generate AD import script |
| `Ctrl+Shift+R` | Export documentation report |
| `Ctrl+Shift+M` | Import description (.md) |

## Edit

| Shortcut | Action |
|---|---|
| `Ctrl+Z` | Undo |
| `Ctrl+Y` or `Ctrl+Shift+Z` | Redo |
| `Ctrl+C` / `Ctrl+V` | Copy / paste an object and its children |
| `F2` | Rename |
| `Del` | Delete |

## Analyse

| Shortcut | Action |
|---|---|
| `Ctrl+Shift+A` | Security audit |
| `Ctrl+Shift+K` | Attack paths |
| `Ctrl+Shift+B` | Before / after |
| `Ctrl+D` | Delegations |
| `Ctrl+T` | Domain Timeline (compare two files) |
| `Ctrl+Shift+S` | AD sites |
